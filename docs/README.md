# Docs

## Purpose

Contains product, architecture, security, operations, implementation plans, ADRs, diagrams, and future documentation portal content.

## Owner Type

Shared ownership across all teams.

## Conventions

- Markdown is the default documentation format.
- Architecture decisions live under `docs/architecture/adrs/`.
- Diagram sources live under `docs/architecture/diagrams/`.
- Implementation plans live under `docs/implementation-plans/`.
- Keep docs close to the contracts and phases they describe.

## Future Phase Dependencies

- Phase 0 created initial product and architecture docs.
- Phase 39 builds the documentation portal.
- Phase 40 validates production support documentation.
